# 0001. 시각 방향: 티켓 타임라인 레이아웃과 크림·복숭아 테마

- 상태: 채택
- 날짜: 2026-10-16

## 배경

forj는 회원가입 없이 공유 링크만으로 여러 사람이 함께 편집하는 여행 일정표입니다. 아기자기하고 귀여운 느낌을 목표로 삼되, 일정 항목을 빠르게 읽고 편집하는 사용성은 해치지 않아야 합니다.

방향을 정하기 위해 여행 화면을 구조가 서로 다른 세 가지 시안으로 만들어 비교했습니다. 시안 코드는 `prototype/design-mockup` 브랜치(커밋 `91cd5b5`)에 보존되어 있습니다.

| 시안 | 구조 |
|---|---|
| A. 티켓 타임라인 | 일차 탭 아래에 왼쪽 정렬 타임라인을 두고, 교통 일정 항목만 탑승권 모양 카드로 보여 줍니다. |
| B. 스크랩북 | 모든 일차를 다꾸 페이지처럼 이어 붙이고, 메모지·폴라로이드·스티커로 장식합니다. |
| C. 지도와 바텀시트 | 지도를 화면 중심에 두고, 일정 항목은 바텀시트 목록으로 보여 줍니다. |

## 결정

1. **레이아웃은 A(티켓 타임라인)를 채택합니다.**
   - 2026-10-16 수정: 일정 항목에 종류를 두지 않기로 하면서([일정 항목의 구성 요소와 정렬 규칙](https://github.com/sunwjy/forj/issues/6)) 교통 일정 항목을 구분할 수 없게 되었습니다. 따라서 MVP에서는 티켓 카드를 쓰지 않고 모든 일정 항목을 일반 카드로 그립니다. 왼쪽 정렬 타임라인 레이아웃은 그대로 유지하며, 티켓 카드는 추후 구현 후보로 남깁니다.
2. **테마는 크림 배경에 복숭아색 강조색만 얹습니다.** 배경, 경계선, 그림자는 크림 계열 중립색을 유지하고, 강조 요소에만 복숭아색을 씁니다.
3. **주 버튼은 선택된 일차 칩과 같은 방식으로 만듭니다.** 연한 복숭아 배경(`#FFD9CC`)에 진한 복숭아색(`#A4482A`)으로 글자, 테두리, 버튼 아래 그림자를 그립니다.
4. **지도 화면은 지금 만들지 않습니다.** 필요해지면 그때 C 시안을 참고해 추가합니다.

구체적인 토큰과 컴포넌트 명세는 [docs/design/visual-design.md](../design/visual-design.md)에 있습니다.

## 검토했다가 버린 선택지

- **B를 메인 화면으로 쓰는 안:** 가장 귀엽지만 정보 밀도가 낮고, 여러 사람이 함께 편집하는 일정표의 주 화면으로는 장식이 과합니다.
- **배경까지 분홍으로 칠한 딸기우유 테마:** 사용자 검토에서 "너무 분홍색"이라는 판단을 받았습니다.
- **딸기 분홍 주 버튼(`#C2416E`, 흰 글자):** 복숭아색이 더 잘 어울린다는 판단에 따라 버렸습니다.
- **파스텔 복숭아 버튼에 짙은 본문색 글자(`#FFB89E` + `#4A3B47`):** 대비는 충분했지만, 버튼에 검은 계열 글자를 쓰는 것이 어울리지 않는다는 판단에 따라 버렸습니다.
- **흰 글자를 쓰는 복숭아 버튼:** 흰 글자로 WCAG AA(4.5:1)를 통과하려면 `#B8553A` 정도까지 어두워져야 하는데, 이 색은 복숭아보다 테라코타에 가깝습니다.

## 결과

- 강조 요소(주 버튼, 선택된 일차 칩, 링크)가 모두 "연한 면과 같은 계열의 진한 글자" 방식으로 통일됩니다.
- 주 버튼의 글자 대비는 4.54:1로 기준(4.5:1)을 겨우 넘습니다. 버튼 글자색을 지금보다 연하게 바꾸면 접근성 기준에 미달하므로, 바꿀 때는 반드시 대비를 다시 계산해야 합니다.
- 다크 모드의 복숭아 토큰은 아직 시안으로 검증하지 않았습니다. 명세에 초안 값만 적어 두었습니다.
